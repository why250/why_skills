# Distill — 本轮对话沉淀

用户通常在一轮工作收尾时说"沉淀一下"。目标：找出值得复用的已验证经验，选对作用域和权威位置，经用户选择后写入。同一内容只维护一个权威来源，其他位置链接引用。

本 skill 只承载流程：产物写入当前任务所属的项目或用户级位置，不写进本 skill 目录，也不自动修改宿主配置。修改本 skill 本身属于技能编辑任务，不套用下面的确认流程。

## 0. 读取附带说明

触发时附带的话决定范围和授权：

- **指定主题**（"沉淀一下 ADS 许可证那段"）→ 只处理该主题。
- **明确授权**（"直接写"、"不用问"、"按约定直接沉淀"）→ 第 3 步简列落点后直接执行授权部分。
- **只说"沉淀一下"** → 完整回顾，展示候选表后等待选择。

## 1. 确定项目与作用域

- 目标项目：用户指定 > 本轮实际修改或讨论的文件所在仓库/子项目。不清楚时只问影响落盘的最少信息；不猜路径，不默认写全局。
- 读取目标位置的 `AGENTS.md`、`CLAUDE.md` 等指令，以及与候选主题相关的现有 skills、文档、规则，遵守其约定。只看相关目录，不遍历主目录或历史 transcript。
- 目标是 `why_skills` 时，按 `docs/skill-lifecycle.md` 的"沉淀原则"执行。

| 作用域 | 适用内容 |
|---|---|
| 项目级（默认） | 依赖本项目代码、环境或约定的知识 |
| 用户级 | 脱离项目仍成立的通用流程，或用户明确要求跨项目生效的偏好 |

用户级产物先去除项目名、绝对路径、内部地址和凭据，必要输入改为参数或发现步骤。

## 2. 回顾本轮，提取候选

按信号强弱扫一遍对话：

| 信号 | 典型去向 |
|---|---|
| 用户纠正（"不对，应该……"、"别再……"） | rule / memory / 已有 skill 的护栏 |
| 失败后跑通：最终可行的命令、参数、顺序 | skill 步骤 / memory（症状 → 根因 → 修复） |
| 同一背景需要解释第二遍 | doc / 项目指令 |
| 重复 2 次以上的手动操作 | 脚本或自动检查 |
| 有理由的重要取舍 | ADR / doc |
| 多步、可重复、触发条件清晰的流程 | skill（优先更新已有） |

只收已验证的结论。**不沉淀**：本轮 diff 清单、临时进度、任务交接/状态快照、已有重复内容、未验证猜测。没有高信号候选时直接说明，不为完成流程造文件。

能用代码或检查自动保证的，优先代码化，而不是写一条靠人记住的规则；代码表达不了的设计理由仍可另写文档。

## 3. 展示候选表

路径来自实际探查；新位置标"建议新建"，未定写"待确定"。

```markdown
| # | 类型 | 作用域 | 内容与理由 | 路径 | 操作 |
|---|------|--------|------------|------|------|
| 1 | memory | 项目 | … | … | 更新 |
| — | 不写 | — | …（已有 / 临时 / 未验证） | — | 跳过 |
```

表后提示：`回复编号即可，如 1 3、all、none，或 2 改为 rule`。

未授权时等待选择；已授权时简列落点后直接执行授权部分，范围外的仍只作建议。

## 4. 落盘

位置优先级：**用户指定 → 已有权威文件 → 项目/宿主约定 → 提议最小新位置**。先读后改，不建平行文档树；冲突无法判断时指出差异，不静默覆盖。一次性小经验追加到现有文件，不为形式新建 skill。

| 类型 | 落点 | 写法 |
|---|---|---|
| 代码 | 所属模块或现有脚本目录 | 最小可运行改动，并实际运行验证 |
| skill | 已有同主题 skill；新建时用宿主可发现的 skills 目录 | 清晰触发条件 + 最终可行流程；细节放 `references/`，脚本放 `scripts/` |
| rule | 现有项目指令文件，尽量缩小生效范围 | 短、可执行；不把项目特例升级为全局规则；普通文档不冒充自动生效的规则 |
| doc | 现有设计或主题文档 | 结构、约定与理由，不复述代码和操作流水账 |
| ADR | 现有决策目录、编号与模板 | 背景、决定、备选项、后果 |
| memory | 宿主实际支持的记忆位置 | 实际日期；适用环境 + 症状 → 根因 → 已验证修复；长内容放文档并链接 |

## 5. 验证与回报

- 改动与授权一致，路径和链接有效，用户级产物不残留私有细节。
- 代码运行相应检查；在 `why_skills` 中新增或修改 skill 后，同步 `README.md` 索引并运行 `python skills/skill-management/maintain-skills/scripts/validate_skills.py`。

简短回报：

- **已写**：类型、作用域、文件、内容
- **未写 / 待确认**：原因与所需信息
- **验证**：做了什么、有何限制
